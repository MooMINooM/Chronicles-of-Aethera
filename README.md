# Chronicles of Aethera

Offline-first 2D top-down fantasy RPG prototype built with Phaser.js.

Current milestone: **v0.1 Greybrook Prototype**.

## Play in browser

After GitHub Pages finishes deploying, the latest `main` build is available at:

https://moominoom.github.io/Chronicles-of-Aethera/

Every merge to `main` automatically rebuilds and redeploys the web app.
